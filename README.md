# M&F Auto Peças — prévia de apresentação

Prévia conceitual de landing page (`noindex`). Não é o site oficial da loja.

- Imagens de cena geradas por IA, apenas ilustrativas: não representam estoque, veículos à venda nem instalações.
- O logotipo é uma reconstrução a partir do avatar público, sujeita à conferência do titular.
- O formulário só monta um resumo na tela do visitante; nada é enviado automaticamente.

Página estática (HTML, CSS e JS, sem dependências). Prévia por Bruno Luque.
